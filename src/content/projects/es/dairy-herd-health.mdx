## Qué es

Estoy trabajando junto a un equipo de 15 veterinarios que atienden unos 50 tambos. Estamos construyendo una plataforma web y mobile nativa para reportes estandarizados de salud de rodeos, inteligencia de negocio y planificación de acciones.

## Cómo está construida

- **Aplicación web:** React y Vite.
- **Aplicación nativa:** React Native y Expo, con **WatermelonDB** para flujos que funcionan offline.
- **Distribución:** Expo para generar el APK de Android.
- **Proceso:** construida con prácticas de AgentOS y Spec-driven Development.
